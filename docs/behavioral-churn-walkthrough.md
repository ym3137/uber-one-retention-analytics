# Behavioral Patterns & Churn — analysis walkthrough

Spoken walkthrough of the Recency x Frequency analysis and the 30-50 day warning zone.

So for this part, I looked at how user behavior explains why members churn after the trial. When we plot Recency against Order Frequency, the pattern is actually very clear. Churned users almost all sit in the high-recency, low-frequency area — meaning they stop using Uber One long before they cancel. So churn isn’t random; it’s a gradual engagement drop that we can identify early. On the other hand, active users are grouped at low recency and higher frequency , which shows they use the membership often and still see ongoing value. What’s interesting is the group in the 30–50 day recency window . Here, active and churned users start to overlap, which basically forms a “warning zone.” These users are becoming inactive but can still be re-engaged with the right nudges. And finally, we also noticed a few high-spend users moving toward higher recency. They’re valuable but at risk, so they’re exactly the people Uber should protect with targeted retention offers. Overall, the behavioral data tells us that churn is predictable, and if we act when recency starts rising, we can meaningfully reduce churn and keep more high-value members.
